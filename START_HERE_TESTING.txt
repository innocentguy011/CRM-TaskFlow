================================================================================
                    ❌ TROUBLESHOOTING
================================================================================

PROBLEM: Workspace doesn't appear after login
  CHECK:
    1. Browser console (F12 → Console tab)
    2. Any JavaScript errors?
    3. Backend logs for exceptions
    4. Did login succeed?
  FIX:
    1. Try manual page refresh
    2. Clear browser cache
    3. Check backend logs for errors
    4. Verify database has workspace_members entry

PROBLEM: Email not received
  CHECK:
    1. Spam folder
    2. Backend logs for email sending
    3. Email configuration in application-dev.yml
    4. SMTP credentials correct
  FIX:
    1. Check "email_logs" table if available
    2. Verify Brevo/SMTP credentials
    3. Check network connectivity

PROBLEM: Notification not appearing
  CHECK:
    1. Database → notifications table
    2. Backend logs for listener errors
    3. WebSocket connection working?
    4. Did invitation really get accepted?
  FIX:
    1. Try manual page refresh
    2. Check WebSocket connection in network tab
    3. Verify NotificationEventListener started

PROBLEM: Wrong role assigned
  CHECK:
    1. Invitation record in database
    2. What role was stored in invitation?
    3. workspace_members table
    4. What role was created for member?
  FIX:
    1. Check invitation.getRole() in backend
    2. Verify role was passed correctly
    3. Create new invitation with correct role

PROBLEM: "Already a member" error
  CHECK:
    1. workspace_members table
    2. Does user already have an entry?
    3. Is it from a previous test?
  FIX:
    1. Delete old workspace_members entry
    2. Create fresh invitation
    3. Test again
