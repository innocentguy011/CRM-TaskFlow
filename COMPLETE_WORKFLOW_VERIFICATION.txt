✓ Flow: Score recalculated based on tasks completed, comments, messages
✓ Status: IMPLEMENTED & WORKING

Check:
  Code: DashboardServiceImpl.java line ~100
    private Double calculateActivityScore(Long tasks, Long comments, Long messages) {
        // Simple scoring: tasks * 3 + comments * 2 + messages * 1
        return (tasks * 3.0 + comments * 2.0 + messages * 1.0);
    }

  How it works:
    - Dashboard endpoint is called with workspace ID
    - For current user, counts:
      * Tasks assigned and completed
      * Comments posted
      * Messages sent
    - Multiplies: (tasks × 3) + (comments × 2) + (messages × 1)
    - Result is cached per workspace per user
    - Cache invalidates on: Create/Update/Delete of tasks, comments, messages
