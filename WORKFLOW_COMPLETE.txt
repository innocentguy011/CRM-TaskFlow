================================================================================
                    WORKFLOW ARCHITECTURE
================================================================================

OWNER CREATES INVITATION:
  Owner Dashboard → Create/Invite → Invitation Record Created
    ↓
  Email Service → Send Invitation Email
    ↓
  Invited User Receives Email

INVITED USER ACCEPTS (EMAIL/PASSWORD):
  Email Link → Click Accept
    ↓
  InvitationAccept.jsx checks: User logged in?
    ↓
  NO: Redirect to /login?invitationToken={token}
    ↓
  User Enters Email/Password
    ↓
  useAuth.login() → onSuccess checks for invitationToken
    ↓
  acceptInvitationAfterLogin(token, jwtToken) called
    ↓
  POST /api/workspaces/invitations/accept/{token}
    ↓
  InvitationServiceImpl.acceptInvitation()
    - Create WorkspaceMember
    - Update invitation status to ACCEPTED
    - Publish InvitationAcceptedEvent
    ↓
  NotificationEventListener handles event
    - Create "You joined" notification (invited user)
    - Create "User accepted" notification (owner)
    ↓
  Frontend invalidates cache
    - window.__queryClient.invalidateQueries(['workspaces'])
    ↓
  Workspace refetched and appears in sidebar
    ↓
  Redirect to workspace dashboard

INVITED USER ACCEPTS (GOOGLE/GITHUB OAUTH):
  Email Link → Click Accept
    ↓
  InvitationAccept.jsx redirects to /login?invitationToken={token}
    ↓
  User clicks "Login with Google" or "Login with GitHub"
    ↓
  LoginForm.jsx preserves token in OAuth URL
    ↓
  /oauth2/authorization/provider?invitationToken={token}
    ↓
  OAuth2SuccessHandler processes successful authentication
    - Find or create user by provider ID
    - Check for pending invitations by email
    - Find matching invitation token
    - Pass invitationToken to frontend
    ↓
  Redirect to OAuth2Callback with token + invitationToken
    ↓
  OAuth2Callback.jsx auto-calls accept endpoint
    ↓
  (Rest same as email/password flow)

NOTIFICATIONS:
  InvitationAcceptedEvent published
    ↓
  NotificationEventListener.handleInvitationAcceptedEvent()
    ↓
  Create 2 Notifications via NotificationService
    - One for invited user
    - One for owner
    ↓
  WebSocketNotificationService sends real-time update
    ↓
  NotificationPanel displays notification
    ↓
  Unread badge incremented
