WORKFLOW VERIFICATION:

✅ Step 1: Email Link Clicked
   - Extracts token from URL parameter
   - Checks if user logged in

✅ Step 2: Redirect to Login (if not authenticated)
   - Preserves invitationToken in URL query parameter
   - Token travels through: /invitations/{token} → /login?invitationToken={token}

✅ Step 3: Login with Token
   - useAuth.js captures invitationToken from searchParams
   - After successful login, calls acceptInvitationAfterLogin()

✅ Step 4: Auto-Accept Invitation
   - POST /api/workspaces/invitations/accept/{token}
   - Backend creates WorkspaceMember row
   - Backend updates invitation status: PENDING → ACCEPTED
   - Backend publishes InvitationAcceptedEvent

✅ Step 5: Event Handling
   - NotificationEventListener creates 2 notifications
   - CacheEvictionListener evicts all caches
   - WebSocket broadcasts notifications

✅ Step 6: Cache Invalidation
   - window.__queryClient.invalidateQueries(['workspaces'])
   - React Query refetches GET /api/workspaces
   - Backend query returns updated workspace list

✅ Step 7: Workspace Appears
   - Newly created WorkspaceMember included in query results
   - Frontend displays new workspace in dashboard
   - Navigates to workspace page
